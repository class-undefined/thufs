本次更新改进了默认启动方式、界面语言选择和 Cargo 安装的更新检测，并新增适合旧版 Linux 的静态安装包。

## 启动与语言

- 直接执行 `thufs` 默认进入交互式 TUI；`thufs tui` 仍可指定初始资料库、本地目录和其他选项。
- 首次启动根据机器语言环境选择 English 或简体中文，支持终端语言变量和 `LANGUAGE` 偏好列表；未设置时读取系统语言，不支持的语言回退为 English。
- 已保存的手动语言设置优先，不会被自动检测覆盖。

## 更新检测

- 根据当前可执行文件对应的 Cargo 安装记录识别安装方式，支持默认安装目录、自定义 `--root` 目录和符号链接。
- Cargo 安装查询 crates.io 的最新稳定版本，排除预发布和已撤回版本；其他安装方式继续查询 GitHub Release。
- 更新详情和 CLI 输出显示检测来源，不同来源的缓存不会混用；继续支持 24 小时缓存、`--force` 和 `--json`。

## 安装包与文档

- 新增 Linux x86_64 musl 静态包，供 CentOS 7 等较旧的 Linux 系统使用。
- 保留 Linux x86_64 GNU、macOS Apple Silicon 和 Windows x86_64 安装包，所有下载包均附 SHA-256 校验文件。
- README 和 TUI 文档同步更新；软件截图位于 README 标题和徽章下方。

## 安装或更新

```bash
cargo install thufs --version 0.2.1 --locked --force
```

旧版 Linux 请在本页下载 `thufs-0.2.1-x86_64-unknown-linux-musl.tar.gz`。
