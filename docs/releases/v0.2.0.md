本次版本扩展了目录下载、交互式云盘工作区和网络设置，保留适合脚本使用的 CLI 输出。

## 文件与下载

- 支持递归下载目录、整个资料库和目录分享链接，保留文件层级、空目录及中文文件名。
- 目录传输显示总进度，支持多选、冲突策略和中断后重试续传；同时选择父目录与子项目时避免重复下载。
- 默认下载到当前用户的 `~/Downloads`，上传与下载分别记住使用过的本地目录。
- 支持整个资料库的模糊搜索，以及分享链接搜索和下载；搜索框位于列表上方。

## 交互式工作区

- 设置页分为界面、网络、版本更新和账号四类，支持鼠标及键盘切换。
- 本地路径输入框支持 Tab 补全，目录选择器中的路径可直接编辑。
- 资料库单击即可切换，传输提示统一显示，并明确标示 `Shift+C` 清理快捷键。
- 关于页新增 ASCII logo、作者和仓库链接；切换账号直接显示用户名或邮箱。
- 文件和目录详情显示修改时间，日期统一换算为上海时间（UTC+8）。
- 中英文文档补充了使用说明，README 开头展示真实终端中的离线演示截图。

## 网络与更新

- 支持自动检测、手动指定和直连三种代理模式。自动模式读取代理环境变量，并在 macOS / Windows 上支持系统静态 HTTP、HTTPS 代理；手动模式支持 HTTP、HTTPS、SOCKS5 和 SOCKS5H。
- 默认 User-Agent 使用 `thufs/<版本>` 标识，支持在设置中自定义。代理与 User-Agent 配置由 TUI、CLI 传输和更新检测共用。
- TUI 启动时后台检测 GitHub 最新稳定版本，结果缓存 24 小时；关于页和设置页均可手动检查，也可关闭自动检测。
- 新增 `thufs update check`，支持 `--force` 跳过缓存和 `--json` 输出。

## 安装或更新

```bash
cargo install thufs --version 0.2.0 --locked --force
```

预编译包提供 Linux x86_64、macOS Apple Silicon 和 Windows x86_64 版本，并附 SHA-256 校验文件。
